## Maintenance

- Add only agreed features; do not maintain a proposed-feature backlog here.
- Assignment rules belong in the assignment guide; student/admin interaction guides must stay consistent.
- Track unresolved choices in the register and link them from the relevant guide.
- Date verification evidence. Claim implemented/passed behavior only when code and checks support it.
- Keep credentials out of documentation; distinguish app admin sessions from developer Convex access.

The former [design.md](../design.md) is now an entry point. See the repository [README](../README.md) for getting started.
